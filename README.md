# Organization defaults

This public repository contains generic default community health files:

- [Pull request template](pull_request_template.md)
- [Contribution guidance](CONTRIBUTING.md)

GitHub uses these files as fallbacks for repositories in this organization that do not provide their own corresponding files. Repository-specific templates and guidance take precedence; these defaults do not replace them.

Pull request titles and descriptions should be in English, including those created through agents, CLI, or API. Tools that do not populate the template automatically must include it explicitly in the PR body.

These files provide guidance, not automatic language validation or merge enforcement. No enforcement workflows are included.

See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
