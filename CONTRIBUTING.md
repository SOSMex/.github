# Contributing

Write pull request titles and descriptions in English.

Use the repository's applicable pull request template. When no local template exists, use [the organization default](pull_request_template.md). Complete Summary, Changes, Validation, Risks and Rollback, Related Issues, and the checklist; explain any section that is not applicable.

This guidance also applies to pull requests created by agents, CLI, or API. Explicitly include the completed template in the PR body when the creation tool does not populate it automatically.

Report only validation actually performed, including commands or manual steps, results, and relevant evidence. If checks were not run, say so and explain why. Do not invent passing tests or results.

Follow repository-specific contribution instructions and review requirements. Keep secrets and sensitive information out of pull requests.
